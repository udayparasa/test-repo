# Basic Calculator Project

This is a simple Python calculator project.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Project Structure

- main.py: Main application file.
- calculator.py: Contains calculator functions.

## Technologies Used

- Python

## How It Works

The main.py file imports mathematical functions
from calculator.py and executes them.

The calculator.py file contains four functions:
add(), subtract(), multiply(), and divide().
